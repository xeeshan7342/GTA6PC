GTA 6 PC native build: status tracker

By GTA6 PC EditorialPublished November 23, 2026

Four different projects could, in theory, put a native GTA 6 build on PC. They are at very different stages. This tracker keeps them separate, because mixing them up is how the fake headlines happen.

Short answerNo native GTA 6 build exists on PC today, from anyone. Rockstar's official build is reported for Q1 2027 but unannounced. AnyPS5 conversion is blocked because GTA 6 is not dumped. KytyPS5 runs GTA V's PS5 build, not GTA 6. The leaked Xbox build is reportedly missing its executable.

Route 1: Rockstar's official native build

Status: not announced, reported Q1 2027. This is the real 'built for PC' version: made from the game's source code, with PC graphics settings, mouse and keyboard, and official support. GamesBeat reported on October 13 that Rockstar plans it for the first three months of 2027, citing four anonymous sources. Rockstar has not commented. Full detail on our release date page.

Route 2: AnyPS5 native conversion

Status: blocked at the dump. AnyPS5 converts PS5 games to run natively on Windows and Linux by rebuilding the PS5's system functions. Its live tracker shows 17,999 of 39,306 functions implemented, and 161 games reaching gameplay. For GTA 6 specifically, the tracker says 'not dumped', because the game needs firmware 14.23 and public jailbreaks stop at 13.60. See the tracker numbers explained.

Route 3: KytyPS5 translation

Status: running other games, not GTA 6. KytyPS5 has run the PS5 version of GTA V on PC, translating Sony's PSSR upscaler to NVIDIA DLSS in the process. That proves a lot about the RAGE engine on PC. It does not run GTA 6, for the same dump reason, plus the game's size and newer system demands.

Route 4: the leaked Xbox build

Status: incomplete files, nothing runs. Cyberleek says it released a near-complete Xbox build of about 209 GB, reportedly without the main executable, with encrypted assets. Xbox games share technology with Windows, which is why this route gets attention, but without the executable there is nothing to run. See can the leaked Xbox build run on PC?

Quick answers

What is a native PC build?

A version of the game compiled to run directly on Windows, with no emulator in between. Rockstar's official PC releases are native builds, and AnyPS5 converts PS5 games into native PC builds.

Which native route is most likely to deliver GTA 6 first?

Rockstar's official version. A GamesBeat report points to Q1 2027, and every fan route is blocked at an earlier step, starting with the missing game dump.

How will I know a native build is real?

It will be announced on Rockstar's Newswire and sold on official stores, or, for a fan conversion, it will appear on the project's own tracker and be reproducible by others.
