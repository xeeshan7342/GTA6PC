Leonida: the GTA 6 Xbox-to-PC recompilation project, explained

By GTA6 PC EditorialPublished November 23, 2026Updated November 24, 2026

Of all the projects that popped up after the GTA 6 Xbox leak, Leonida got the most attention, until it shut down on November 24, 2026. Here is what it was, what it achieved, and why it never ran GTA 6.

Short answerUpdate, November 24, 2026: Leonida has shut down. Its developer stepped away, its GitHub page is no longer accessible and its Discord server was taken down. Before that, the project had translated 26,503 shaders to Vulkan's SPIR-V format, but the game never booted through Leonida. Full story in our crackdown report.

Update, November 24, 2026: Leonida has shut down. Its main developer stepped away, citing circumstances beyond his control, and the project's GitHub page and Discord server are gone. The rest of this article explains what the project was and what it achieved. Full story in our crackdown report.

What Leonida is

Leonida is an open-source project, named after GTA 6's fictional state, that wants to run the Xbox Series version of GTA 6 natively on Windows. It's often called an "emulator," but it isn't one. It uses static recompilation, translating the game's code into a PC program ahead of time instead of emulating an entire Xbox. We explain the difference in Is GTA 6 built for PC?

What it has achieved

  • 26,503 shaders extracted from the Xbox version and translated into SPIR-V, the format Vulkan graphics uses on PC.
  • Asset extraction works for much of the game, though some file layouts and BCPack-compressed textures aren't supported yet.

That's real technical progress. Graphics shaders are one of the hardest parts of moving a console game to PC.

What it can't do yet

  • The game doesn't boot. The project's own developers say so.
  • It never booted the game. The project's own developers said so, and the executable only arrived on November 23, the day before the project shut down. See our Cyberleek update and our crackdown report.
  • Xbox system functions still need to be rebuilt for Windows.

How it relates to the leak

Leonida says users need their own copy of the Xbox Series package, version 1.0.2.1, and that it doesn't distribute any game files. Version 1.0.2.1 is also the version reported for the leaked build. Coverage has noted that the leak sparked a wave of similar projects, with some estimates of thousands on GitHub, though that figure is unverified.

Is it safe or legal?

The tool itself is code, and recompilation projects for older games have existed for years. Getting GTA 6's files from a leak is piracy, though. Unofficial "Leonida download" or "Leonida GTA 6 build" sites are also a prime malware risk. Only follow the project through its official source, and never download game files.

Will Leonida beat Rockstar to PC?

Unlikely. Rockstar's official PC version is reported for early 2027, which may be only a few months away. A fan recompilation of a game this big would need far more than a few months to become playable, if it ever does.
