AnyPS5 and GTA 6: can PS5 games run on PC without an emulator?

By GTA6 PC EditorialPublished November 24, 2026

A 24/7 livestream tracking an open-source project called AnyPS5 has become one of the most-watched things in gaming this week. People want to know one thing: does it mean GTA 6 on PC? Here's the honest answer.

Short answerAnyPS5 is real, open source, and has some PS5 games reaching gameplay on PC. But GTA 6 isn't one of them. The game hasn't been dumped from a PS5, it requires firmware 14.23, and public PS5 jailbreaks only reach 13.60. Don't trust anyone offering "GTA 6 via AnyPS5" downloads.

What is AnyPS5?

AnyPS5 is an open-source project that tries to run PS5 games on Windows and Linux without emulating the console. Its official code is on GitHub, and it has quickly become one of the most-starred projects of its kind.

Instead of pretending to be a PS5, it takes a game's PS5 program and relinks it into a native PC program. That's possible because the PS5 uses an AMD Zen 2 processor, the same x86-64 type of chip that's in PCs. The hard part is everything around the processor, so the project also:

  • Rewrites the PS5's system libraries so games can call them on a PC.
  • Recompiles the console's graphics shaders to run on Vulkan.

Tom's Hardware compared the idea to Proton, the tool that lets Windows games run on Linux. It translates the parts that differ instead of emulating a whole machine.

How far has it got?

As of November 23, 2026, a live progress tracker streamed on YouTube showed:

These numbers change daily. "Reaching gameplay" also doesn't mean a game is fully playable, and most of the games that work so far are small titles, not huge open worlds.

Why GTA 6 isn't running on AnyPS5

AnyPS5 doesn't come with any games. It needs the game's files, taken from a PS5 that the player has jailbroken. For GTA 6, that hasn't happened yet:

  1. GTA 6 requires PS5 firmware 14.23. Sony released it on November 17, two days before launch, with notes that only mention "security fixes," and made it mandatory to play GTA 6.
  2. Public PS5 jailbreaks only work up to firmware 13.60. A security researcher claimed to have dumped a game on 14.22, but didn't say which game or share details, and Sony patched again the next day.
  3. So nobody can legally pull GTA 6 off their own PS5 yet, which means there's nothing for AnyPS5 to run.

Even once that changes, a game as big and complex as GTA 6 would likely need a lot more of the PS5's system functions working before it got past loading screens.

Is AnyPS5 legal?

Projects that reimplement a console's software, like emulators, are generally legal in many countries. Downloading games you don't own is not. AnyPS5 is designed for players who dump games from their own console. Using pirated copies, or game files shared online, is piracy, and those files are a common way to spread malware.

Watch out for fake "AnyPS5 GTA 6" downloads

There is no GTA 6 build for AnyPS5. Expect fake "AnyPS5 + GTA 6" packs, unofficial AnyPS5 sites and YouTube links promising it works. Only get AnyPS5 from its official GitHub page, and never download GTA 6 game files from anyone. See our guide to fake GTA 6 PC downloads.

So when can PC players actually play GTA 6?

The realistic answer is still Rockstar's official PC version, which a GamesBeat report says is targeting the first quarter of 2027.
