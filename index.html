Native vs. port

Built for PC means something

Here's the difference between a game made for your platform and one that was moved over later.

Native PC build

  • ✓ Mouse and keyboard controls designed in, not bolted on
  • ✓ Graphics settings that scale from mid-range to high-end rigs
  • ✓ Support for ultrawide and high refresh rate displays
  • ✓ Menus and UI laid out for a desk, not a couch
  • ✓ Performance tuned for PC CPUs, GPUs and storage

Typical console port

  • ✕ Controller-first menus with mouse support as an afterthought
  • ✕ Locked framerates and limited settings
  • ✕ Black bars on wide screens
  • ✕ Button prompts that don't match your keyboard
  • ✕ Stutter from engines built for fixed hardware
